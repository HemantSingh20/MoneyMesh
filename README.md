# MoneyMesh 💰

**Split. Track. Settle Together.**

MoneyMesh is a MERN Stack based personal finance and expense-sharing web application that helps users manage budgets, track expenses, split group expenses, and calculate optimized settlements.

## Features

- User Authentication (JWT)
- Personal Budget Management
- Category-wise Expense Tracking
- Monthly Spending Analysis
- Trip Expense Management
- Group Expense Splitting
- Optimized Settlement Calculation
- Responsive Dashboard
- Docker Support

## Technology Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JWT Authentication

### Deployment
- Docker

## Installation

```bash
git clone https://github.com/HemantSingh20/MoneyMesh.git

cd MoneyMesh

npm install
```

## Run Application

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Backend:

```bash
cd backend
npm install
npm run dev
```
